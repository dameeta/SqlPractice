Scenario: Audit Insertions in Sales.SalesOrderHeader
 
Create a trigger to log every new sales order added to Sales.SalesOrderHeader into a custom audit table.

Step 1: Create the Audit Table

CREATE TABLE Sales.SalesOrderAudit (
    AuditID INT IDENTITY(1,1) PRIMARY KEY,
    SalesOrderID INT,
    CustomerID INT,
    OrderDate DATETIME,
    TotalDue MONEY,
    CreatedAt DATETIME DEFAULT GETDATE()
);

Step 2: Create the Trigger

CREATE TRIGGER trg_AuditSalesOrderInsert
ON Sales.SalesOrderHeader
AFTER INSERT
AS
BEGIN
    INSERT INTO Sales.SalesOrderAudit (SalesOrderID, CustomerID, OrderDate, TotalDue)
    SELECT 
        SalesOrderID, 
        CustomerID, 
        OrderDate, 
        TotalDue
    FROM INSERTED;
END;

 Notes:
INSERTED is a pseudo-table that holds the newly inserted rows.

Triggers can also be created for UPDATE or DELETE actions.

It's a best practice to keep trigger logic simple and avoid long-running operations.
